# Latin Modern Roman

Pliki fontów pochodzą z pakietu Latin Modern 2.005 dostępnego w
[CTAN](https://ctan.org/pkg/lm). Do książki dołączono odmiany kroju o rozmiarze
projektowym 10 punktów: zwykłą, pogrubioną, kursywę oraz pogrubioną kursywę.

Fonty są rozpowszechniane na warunkach GUST Font License. Pełny tekst licencji
znajduje się w pliku `GUST-FONT-LICENSE.txt`.
